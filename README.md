# CS2 Match Desk

Это проект Next.js. Содержимое этой папки можно загрузить в **корень** репозитория GitHub, сохранив структуру папок `src`, `public`, `prisma`, `scripts` и `tests`. В комплекте более 100 файлов: если сайт GitHub ограничит размер одной загрузки, загрузите папки и корневые файлы в несколько приёмов.

GitHub хранит исходный код. Чтобы приложение заработало как сайт, подключите репозиторий к сервису, поддерживающему Next.js с серверными API, например Vercel. GitHub Pages для этого приложения не подходит.

Для сохранения архива в PostgreSQL задайте переменную окружения `DATABASE_URL` в настройках хостинга. Не загружайте пароль или настоящий `.env` в репозиторий. Схема базы находится в `prisma/schema.prisma`; её применение к базе меняет базу данных, поэтому выполняйте его только после создания резервной копии и проверки целевого подключения. Если таблица уже существует, проверьте совместимость схемы до изменений.

**Безопасность:** API архива сейчас не защищён авторизацией. Публичный сайт, подключённый к базе, может позволить посторонним читать, изменять и удалять записи. Перед публичным доступом настройте защиту API. `/api/debug` также раскрывает сведения о базе и последних матчах.

Локальная разработка требует Node.js, установленных зависимостей и доступной PostgreSQL:

```bash
npm install
```

```bash
npm run dev
```

Проверки:

```bash
npm test
```

```bash
npm run typecheck
```

```bash
npm run lint
```
